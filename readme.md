# Exe — Landing Page

Exe is a responsive one-page landing website for a business/agency concept. It features a structured marketing layout with multiple sections (features, portfolio, skills, blog, clients, and contacts) and basic interactive UI elements.

## Live Demo
- https://valentyn-m.github.io/Exe_Landing-page/

## Key Features
- One-page layout with anchor navigation across sections (Home, Features, Portfolio, Skills, Blog, Clients, Contacts)
- Hero section with clear headline and call-to-action buttons
- “Advantages / Features” block with highlight cards
- Portfolio / works showcase section with project cards
- Skills section with progress-style indicators
- Blog preview section for latest posts
- Clients/logo section for social proof
- Contact section with a simple form (name/phone/message)
- Responsive layout built with modern CSS (Grid/Flexbox)

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- JavaScript
- jQuery
